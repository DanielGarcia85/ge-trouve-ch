# Réponse pilote — Où déposer ma demande de permis de séjour ?

## Réponse

Vous pouvez déposer votre demande de permis de séjour auprès de l'OCPM.

Selon les modalités de dépôt, vous avez deux options :
*   **En ligne** : Vous devez disposer d'un compte e-démarches de type simple pour effectuer la démarche sur le portail.
*   **Par courrier**.

Source : https://www.ge.ch/demander-permis-sejour-ma-famille-regroupement-familial/je-suis-suisse
